# planning

**Where a feature lives before it is a change.** One file per feature,
`planning/<name>.md`, named the way the change would be named. Nothing here is
proposed.

```
  planning/<name>.md        the feature, argued. NOT PROPOSED.
        ▼
  design/<component>.md     the mechanism, with an Archify chart
        ▼
  openspec/changes/<name>/  proposal · design · specs · tasks
        ▼
  openspec/specs/<cap>/     the requirement, after the archive
```
